# Screenshots Folder

This folder contains screenshots of the Fuel Price Analytics Dashboard.

## Required Screenshots

Please capture and add the following screenshots:

1. **dashboard-full.png** - Full dashboard view showing all sections
2. **latest-prices.png** - Close-up of the Latest Prices section
3. **monthly-trends.png** - Monthly trends line chart
4. **city-comparison.png** - City comparison bar chart

## How to Capture Screenshots

1. Run the application: `npm run dev`
2. Open the app in your browser
3. Use browser developer tools or a screenshot tool to capture full-page screenshots
4. Save images to this folder with the names listed above

## Recommended Tools

- **Windows:** Snipping Tool or Win + Shift + S
- **macOS:** Cmd + Shift + 4
- **Browser Extensions:** Full Page Screen Capture, GoFullPage
